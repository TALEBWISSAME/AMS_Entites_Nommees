# Rapport du TP

Ce dossier accueillera le rapport du TP Entités Nommées. Le rapport final n’est pas encore rédigé.

L’énoncé `docs/AMS1_EN (1).pdf` (page 3) demande un **petit rapport de 2 à 3 pages sur les algorithmes**, accompagné des **listes L, LP, LL et des statistiques du corpus**. Les thèmes ci-dessous devront donc être traités de façon synthétique, sans multiplier artificiellement les sections.

Il documentera progressivement :

- l’objectif et le corpus ;
- la méthodologie et le prétraitement ;
- la tokenisation et les n-grammes ;
- le modèle de langue et les heuristiques ;
- les méthodes de construction de L, LP et LL ;
- les statistiques et les résultats réellement obtenus ;
- les limites et les améliorations possibles.

Justifier les choix à partir des observations et consignes disponibles. Ne pas inventer de résultats ni reproduire de longs extraits du corpus.
